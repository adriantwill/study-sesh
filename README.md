# Study Sesh

AI-powered PDF-to-flashcard study tool.

Upload a PowerPoint PDF, extract slides with Poppler, generate study questions with fine tuned Qwen model, then review them as flashcards or quizzes.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- PostgresSQL
- S3 Object store
- node-poppler
- RunPod Serverless 

## Features

- PDF upload and question generation
- Text-to-question deck creation
- Flashcard study mode
- Quiz mode
- Folder organization
- Inline editing for questions, answers, titles, and folders
